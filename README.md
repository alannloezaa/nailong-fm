# Nailong FM

Reproductor personal de música en HTML, CSS y JavaScript.

Catálogo: 72 canciones, 55 álbumes y sencillos. La publicación incluye un único audio: MONET, proporcionado por el usuario. El resto del catálogo contiene datos y carátulas; no implica que el audio esté incluido.

Los archivos agregados desde Personalizar se guardan solo en el dispositivo actual. Para compartir más canciones por enlace deben añadirse los audios a esta publicación y declararse en media.json. Las letras se consultan en LRCLIB cuando hay una versión compatible.

Spotify es la opción principal. Los enlaces de Spotify y Apple Music abren canciones o búsquedas; no conectan cuentas.

Esta exportación contiene los recursos en una única carpeta y conserva los archivos de audio sin recomprimir.
